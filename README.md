# PTW

Видеоплеер для Windows с выбором аудиодорожек: можно слушать одну дорожку или все сразу
и отдельно настроить громкость каждой (удобно для записей NVIDIA ShadowPlay / OBS,
где системные звуки и микрофон лежат на разных дорожках).

## Установка

Скачайте `PTW-Setup-<версия>.exe` из раздела Releases и запустите.
Права администратора не нужны. Обновления PTW проверяет и ставит сам.

## Клавиши

| Клавиша | Действие |
|---|---|
| Пробел, клик по видео | пауза |
| ← → | перемотка на 5 с |
| ↑ ↓, колёсико | громкость |
| 1 / 2 / 3 | 1 дорожка / 2 дорожка / все дорожки |
| F, Enter, двойной клик | полный экран (Esc — выход) |
| M | без звука |
| [ ] | скорость (Backspace — 1×) |
| Ctrl+O | открыть файл |

## Разработка

- `src/` — код (Python 3.12, PySide6, python-mpv): `ptw.py` — окно плеера, `ui.py` — элементы интерфейса
- `build.ps1` — сборка `dist\PTW-Setup-<версия>.exe` (нужны PyInstaller и Inno Setup 6)
- `release.ps1` — выпуск новой версии на GitHub: поднять `__version__` в `src/version.py`,
  дописать `CHANGELOG.md`, закоммитить и запустить скрипт
